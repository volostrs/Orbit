# Orbit

Orbit is a note-taking and organization app designed to help students with ADHD manage their schoolwork.

## Features

- Note-taking with BlockNote
- Organized workspaces
- Tables and charts
- Habit tracking
- AI-assisted support

## Technologies

- React
- JavaScript
- Node.js
- Tailwind CSS
- BlockNote
- PostgreSQL
- Neon

## Installation

1. Clone the repository.
2. Install dependencies.
3. Configure the required environment variables.
4. Start the development server.

See the project configuration and environment variable examples for the exact setup requirements.
